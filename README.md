# Einflussfaktoren auf den Filialumsatz von Rossmann

Ein Projekt im Rahmen der Vorlesung Business Analytics an der DHBW Bad Mergentheim (Kurs DBM 25).   
Autoren: Lucienne Dorbath, Emely Helwer, Cedric Weber   
Kurze Beschreibung: Im Einzelhandel schwankt der Tagesumsatz einer Filiale stark. Ziel dieses Projekts ist es, mit Python in einem Jupyter Notebook zu analysieren, welche Faktoren den Umsatz von Rossmann-Filialen beeinflussen und wie Rabattaktionen sowie Filialmerkmale mit den Umsatzzahlen zusammenhängen.

Im Zentrum stehen zwei Forschungsfragen:
Forschungsfrage 1 (FF1): Wie stark erhöht eine Rabattaktion (Promo) den Tagesumsatz einer Rossmann-Filiale, und unterscheidet sich diese Wirkung je nach Wochentag?   
Forschungsfrage 2 (FF2): Wie hängen Filialtyp, Sortiment und Entfernung zur Konkurrenz mit dem Umsatz und dem Umsatz pro Kunde zusammen?   

Als Datengrundlage dient der Kaggle-Datensatz Rossmann Store Sales mit Verkaufsdaten von 1.115 Rossmann-Filialen in Deutschland.   

Quick StartVoraussetzungenPython 3.xJupyter Notebook (oder JupyterLab / Visual Studio Code)Benötigte Python-Bibliotheken: pandas, numpy
